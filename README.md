# Medina Tasadores, SRL. — Sistema de Ajuste de Seguros

Aplicación web para gestión de casos de ajuste de seguros.

## Configuración

1. Crea un archivo `.env.local` en la raíz con:
```
NEXT_PUBLIC_SUPABASE_URL=tu-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=tu-anon-key
```

2. `npm install`
3. `npm run dev`
